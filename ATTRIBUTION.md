`public/assets/manifest.json` records individual download URLs, creators, licenses, modifications and SHA-256 checksums. Source files were downloaded through Poly Haven's public asset catalog, not extracted from preview renders. Color maps use sRGB; normals and roughness use linear data color space. OpenGL normals are used without a DirectX green-channel inversion. Runtime geometry supplies meter-based projected UVs for buildings/terrain and conventional UVs for first-person models.

The village layout, modular geometry, roof corrugation, mountains, vegetation, vehicles, articulated character rigs, hands, weapon meshes, signs, contact-shadow texture, interface and synthesized audio are original project content. The prior procedural models remain a loading/failure fallback. The character polish pass now includes the CC0 human body and animation sources listed below; weapon and building models remain original. The selected Quaternius clips are authored animations, with original procedural grip, stance and foot-placement overlays; no motion-capture library is included. The market produce (including curved banana meshes), striped watermelon/fabric canvas textures, baskets, weighing scale, tea kettle/cups, handcart, scooters, bicycle, drains, scarves and clothing details added in the market update are also original project content. That market update reused existing CC0 PBR maps. Its environment and weapon meshes are original runtime geometry; the subsequent character sources are listed below.

Three.js and its RoundedBoxGeometry / RoomEnvironment addons are MIT licensed; see `node_modules/three/LICENSE`. Other npm dependencies retain their own licenses. Fonts are system fonts. Poly Haven logos, website text and preview images are not bundled.

## Character polish assets

- **Quaternius — [Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html), Standard Superhero Male FullBody.** CC0 1.0, expressly listed on the creator's official pack page. Contains the modeled human face/ears, body, articulated hands, skin/eye/hair maps and humanoid skeleton. Official free Standard source, retrieved through [this attributed source mirror](https://github.com/NafisRayan/Animate-Rigged-Humanoid-No-Blender) because the creator's temporary itch download link redirected to its listing. No paid Source assets were used.
- **Quaternius — [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html), Standard.** CC0 1.0 on the official pack page and included license file. Sixteen selected TPose, idle, walk/jog/sprint, crouch, jump/landing, hit, death and pistol reference clips. Clips were sampled at 30Hz, calibrated from mannequin rest pose to body proportions, stripped of gameplay root translation and compacted into a local GLB. Original source license is bundled as `public/assets/characters/CC0-Quaternius.txt`.
- **Rob Tuytel — [Denim Fabric](https://polyhaven.com/a/denim_fabric), Poly Haven.** CC0 1.0. Local 1K base color, OpenGL normal and roughness maps. Applied with meter-scaled rest-space UVs and subdued jacket/jean/glove tints.

Runtime files are `crew-base.glb`, `crew-motion.glb` and three denim JPEGs, bundled locally under `public/assets/characters/`. Body image maps were optimized to 1K; eye/hair maps to 256px. New clothing region geometry, cuffs, boots/soles, scarves, pockets, zipper, team patterns, first-person arm cropping, IK constraints and code are BLACKOUT project modifications. Source URLs, mirror revision, modifications and output SHA-256 hashes are in `public/assets/manifest.json` under `characterAssets`. No hotlinked runtime asset, extracted commercial-game content, paid dependency or external character service is used.
